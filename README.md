# DungeonSeeker

Данжен-кроулер на Unity: хаб, забеги в подземелье, инвентарь и союзник с ИИ (в том числе ML-Agents).

## Стек

- Unity `6000.0.67f1`
- C#, NavMesh, Scriptable Objects
- Союзный ИИ: `AllyAIBrain`, восприятие, таргетинг, способности
- Обучение: Unity ML-Agents (`ml-agents/`, результаты в `results/`)

## Что есть в игре

- Хаб и забег: экип переносится в ран, при победе вещи возвращаются, при поражении лут забега теряется (`RunSystem`)
- Инвентарь на Scriptable Objects
- Игрок, враги, снаряды, окружение
- Союзник, который держит позицию и участвует в бою
- Скрипт обучения: `ml-agents/train_ally_position.ps1`

## Как открыть

1. Поставь Unity `6000.0.67f1`.
2. Открой папку репозитория как проект.
3. Дождись импорта пакетов (включая ML-Agents, если они в манифесте).

Обучение союзника — из `ml-agents/` после настройки Python-окружения ML-Agents.
